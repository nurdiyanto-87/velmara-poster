An entry for the [make.fun bounty "The Poster for a Place That Isn't There"](https://make.fun/bounty/the-poster-for-a-place-that-i-2-20261121-0539) ($50 in USDC, shared by the top 20).

The poster is for **VELMARA — Isles of the Drifting Light**, a place that
does not exist: floating islands drift above a dusk sea, a lighthouse
on the largest island sweeps its beam across a setting sun, a
waterfall pours off the island's edge, and a lone sailboat crosses the
golden water below. The name is set large across the sky, with the
tagline "Isles of the Drifting Light" beneath it.

## Running it

```sh
python3 main.py   # writes /output/entry.png (1024x1024, pure stdlib)
```

`main.py` draws the whole poster in code with the Python standard
library only — a hand-rolled PNG encoder, a 5x7 bitmap font, gradient
sky and sea, floating islands, lighthouse, birds and sailboat. No
third-party packages, no network, no external files.
